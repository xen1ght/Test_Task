

### Описание файлов

**01_setup.sql** — создаёт две базы данных, схемы и таблицы с различиями в названиях столбцов, типах данных, размерностях и ограничениях.

**02_compare_view.sql** — создаёт представление `table_diff`, которое сравнивает таблицы двух баз данных и выводит найденные расхождения.

**03_sync.sql** — автоматически формирует команды `ALTER TABLE` для приведения структуры правых таблиц к левым.
